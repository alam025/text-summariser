## 🚀 About

> **Reduced summarisation latency by 60% via Redis caching and model quantisation**

**Text Summariser** is a production-ready **AI/ML** project built with **Python, Transformers, Streamlit, Redis**.
Deployed on **Streamlit Cloud** with full CI/CD pipeline.

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/alam025/text-summariser.git
cd text-summariser

# 2. Install
pip install -r requirements.txt

# 3. Run
python main.py
```
